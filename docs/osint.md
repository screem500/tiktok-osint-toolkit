# 🔎 دليل الاستخبارات مفتوحة المصدر (OSINT)

**[English Version 🇬🇧](osint.en.md)**

> **OSINT = Open Source Intelligence**: جمع وتحليل المعلومات من مصادر **متاحة للعموم** (مواقع، شبكات اجتماعية، سجلات حكومية، أرشيف الويب) لأغراض بحثية أو صحفية أو أمنية مشروعة.

---

## 🧭 دورة الاستخبارات (Intelligence Cycle)

1. **التخطيط والتوجيه**: حدّد سؤالك البحثي بدقة (ماذا تريد أن تعرف؟ ولماذا؟).
2. **الجمع**: اجمع البيانات من المصادر العامة المتاحة.
3. **المعالجة**: نظّم البيانات وصنّفها (جداول، خرائط زمنية، روابط).
4. **التحليل**: استخرج الأنماط والعلاقات والاستنتاجات.
5. **النشر**: قدّم النتائج بشكل واضح مع توثيق المصادر.
6. **التغذية الراجعة**: هل أجبت على السؤال؟ هل تحتاج جولة جديدة؟

## 🕒 استخراج وقت النشر من رقم المنشور (تيك توك)

كل رابط منشور في تيك توك ينتهي برقم من 19 خانة:

```
https://www.tiktok.com/@username/video/7474502610695851270
                                       ^^^^^^^^^^^^^^^^^^^ معرّف المنشور
```

هذا الرقم ليس عشوائيًا. تيك توك يولّده بنمط **Snowflake**، حيث يُخزَّن وقت الإنشاء داخل الرقم نفسه: أول **32 بت** (من تمثيله بـ 64 بت) هي عدد الثواني منذ 1 يناير 1970 (Unix time)، والبتات الباقية بيانات داخلية للخادم والتسلسل.

النتيجة: **كل رابط يحمل تاريخه معه**، بدون أي API وبدون فتح المنشور.

### الطريقة

أزِح الرقم 32 بتًا إلى اليمين، فتحصل على الطابع الزمني بالثواني:

```
7474502610695851270 >> 32 = 1740293253  →  2025-02-23 06:47:33 UTC
6945422069853179138 >> 32 = 1617107090  →  2021-03-30 12:24:50 UTC
```

والإزاحة 32 بتًا تعادل القسمة على 2³² = 4294967296 مع تجاهل الباقي.

**JavaScript** (وهي المستخدمة داخل الأداة):

```js
new Date(Number(BigInt(id) >> 32n) * 1000).toISOString();
```

**Python**:

```python
from datetime import datetime, timezone
datetime.fromtimestamp(int(post_id) >> 32, timezone.utc).isoformat()
```

**Bash**:

```bash
date -u -d @$(( 7474502610695851270 >> 32 ))
```

### مزلقان شائعان

**1. لا تستخدم نوع الأرقام العادي في JavaScript.** معرّف المنشور 19 خانة، وأكبر عدد صحيح آمن في JavaScript هو `9007199254740991` (16 خانة)، فالتحويل بـ `Number` يفسد آخر الخانات:

```js
Number("7474502610695851270") // 7474502610695851000 ← فقدت الدقة
```

لذلك يُقرأ المعرّف بـ `BigInt`، ثم يُحوَّل الناتج الصغير (الطابع الزمني) إلى `Number`.

**2. إن حوّلت الرقم إلى ثنائي يدويًا، أكمِله إلى 64 بت أولًا.** المعرّف أعلاه طوله 63 بتًا فقط، فأخذ أول 32 خانة من تمثيل غير مكتمل يعطي `3480586507` وهو تاريخ خاطئ، بينما التمثيل المكتمل بـ 64 بت يعطي `1740293253` وهو الصحيح. استخدام الإزاحة `>> 32` يتجنب هذا الخطأ تمامًا.

### التحقق من الناتج

افتح المنشور وقارن التاريخ المعروض. لاحظ أن تيك توك يعرض التاريخ **بتوقيتك المحلي**، بينما الناتج أعلاه **بتوقيت UTC**، فقد يختلف اليوم عند حدود منتصف الليل (فرق السعودية +3 ساعات).

### لماذا يهم في التحقيق

- بناء خط زمني كامل للحساب من قائمة روابط فقط.
- استنتاج المنطقة الزمنية المرجّحة من ساعات النشر المتكررة.
- كشف الحسابات التي رُفع محتواها دفعة واحدة خلال دقائق.
- التحقق من ادعاء زمني: هل المنشور سابق للحدث أم لاحق له؟
- مقارنة حسابين يُشتبه بأنهما يُداران من الشخص نفسه.

### حدود الطريقة

- الوقت هو لحظة توليد المعرّف على خوادم تيك توك، لا وقت التصوير، وقد يختلف بثوانٍ عن لحظة ظهور المنشور.
- لا يخبرك **من** نشر، ولا إن كان الوصف أو المحتوى عُدّل لاحقًا.
- تغيير اسم الحساب لا يؤثر على المعرّف — وهذا في صالحك — لكنه لا يثبت ملكية الحساب.
- التاريخ وحده ليس دليلًا: وثّقه مع الرابط ولقطة الشاشة ووقت الجمع كما في [أساسيات التحقيق الجنائي الرقمي](digital_forensics.md).

## 🛡️ حماية الباحث (OPSEC)

- استخدم **ملف تعريف متصفح منفصل** (أو جهازًا افتراضيًا) لأنشطة البحث.
- لا تتفاعل مع الهدف (لا إعجاب، لا متابعة، لا رسائل) — المراقبة فقط.
- وثّق كل شيء: الرابط + التاريخ + لقطة الشاشة، لأن المحتوى قد يُحذف.
- لا تنشئ حسابات وهمية لانتحال هوية أشخاص حقيقيين — هذا غير قانوني في معظم الدول.

> 🚨 **تنبيه خاص بتيك توك — سجل مشاهدات الملف الشخصي**:
> يملك تيك توك ميزة «سجل مشاهدات الملف الشخصي» (Profile View History). إذا كانت مفعّلة **لديك ولدى صاحب الحساب**، فسيظهر له أنك زرت صفحته. والأخطر: الزيارة التي تمت والميزة مفعّلة **تبقى مسجلة لديه حتى لو أطفأت الميزة لاحقًا**.
> لذلك، **وقبل** فتح حساب الهدف (وليس بعده):
> - تصفّح **دون تسجيل دخول** متى أمكن، أو استخدم **حسابًا بحثيًا مخصصًا** لا يكشف هويتك.
> - تحقق من الإعداد: `الملف الشخصي ← ☰ ← الإعدادات والخصوصية ← الخصوصية ← سجل مشاهدات الملف الشخصي`.

## ⚖️ تذكير
