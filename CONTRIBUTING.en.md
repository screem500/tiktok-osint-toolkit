# 🤝 Contributing Guide

**[النسخة العربية](CONTRIBUTING.md)**

Thank you for your interest in contributing to this project!

## How to Contribute

1. **Fork** the repository to your account.
2. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes following the guidelines below.
4. Submit a **Pull Request** with a clear description of the change.

## Welcome Contributions

- 🐛 Bug fixes in the scripts.
- ✨ New tools for collecting public data (must comply with the legal guidelines).
- 📚 Improving or translating the guides.
- 🔗 Adding useful OSINT tools to the resource lists.

## Guidelines

- Any new tool must work on **public data only**, without bypassing technical protections.
- Code comments should be in both Arabic and English.
- Update the README files if you add a new feature.
- Never include real personal data in examples or screenshots.

## Reporting an Issue

Open an **Issue** with:
- A description of the problem and steps to reproduce it.
- Your browser type and version.
- The error message from the Console (if any).
